# Kodu UI - Project Overview (v2.1)

## 1. Core Concept

**Kodu UI** is a developer resource hub designed to accelerate the building of modern applications. We provide both **"The Body"** (Components & Layouts) and **"The Brain"** (Logic & Utilities) in a single, seamless experience.

> **Motto:** _Copy. Paste. Ship._

---

## 2. What We Offer

- **Enhanced Components:** A curated collection of UI elements built on **shadcn/ui**, refined for higher aesthetics and specific use cases.
- **Structural Blocks:** High-level sections for rapid assembly, including _Hero sections_, _SaaS Headers_, _Pricing Tables_, and _Dashboards_.
- **Developer Utils (The Brain):** A library of copy-pasteable TypeScript helper functions and Custom Hooks to handle repetitive logic like currency conversion, date formatting, and DOM manipulation.

---

## 3. Why Kodu UI?

- **Zero-Friction Access:** No authentication or sign-up required. Access the core library instantly.
- **Logic-Integrated UI:** We don't just give you the interface; we provide the utility functions to make it functional.
- **One-Click Copy:** Seamlessly integrate code into your project with a built-in "Copy to Clipboard" feature.
- **High Performance:** Optimized for **Next.js**, **Tailwind CSS**, and **TypeScript** to ensure your projects remain lightweight and type-safe.

---

## 4. Tech Stack

- **Frontend:** Next.js (ISR) & Tailwind CSS
- **Design Base:** shadcn/ui
- **Backend & Data:** Supabase & Prisma

---

## 5. Monetization & Support

- **Public Library:** Core components and essential utilities are free for everyone.
- **Blocks:** Complex, production-ready layouts for rapid assembly.
- **Community Driven:** Supported by users through donations via **Trakteer** or **Buy Me a Coffee**.
